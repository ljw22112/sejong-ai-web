# 세종대 공학인증 점검

성적증명서(PDF)나 학사정보시스템 기이수성적 표를 넣으면 세종대학교 공학교육인증(ABEEK) 졸업요건 충족 여부를 영역별로 판정하고, 부족한 부분을 희망 진로에 맞춰 남은 학기에 배치해 주는 정적 웹앱입니다.

배포 주소: https://ljw22112.github.io/sejong-ai-web/

## 하는 일

- **성적 읽기**: 성적증명서 PDF(2~3단 배치, 칸 안 줄바꿈, ‘제1학기’ 표기 포함), 글자 정보가 없는 이미지형 PDF·캡처 이미지(브라우저 안 글자 인식), 학사정보시스템 기이수성적 엑셀(XLSX), CSV/TXT, 복사·붙여넣기를 지원합니다. 읽은 과목명은 표에서 바로 고칠 수 있습니다. 학번에 따라 이름이 바뀐 과목(예: 기초미적분학 ↔ 미적분학1)은 같은 과목으로 맞춰 보고 화면에 표시합니다. 재수강은 마지막 통과 기록만, F·NP·W는 제외합니다. 모든 처리는 브라우저 안에서 이뤄지고 서버로 보내지 않습니다.
- **판정**: 전문교양·MSC(BSM)·전공·설계 최소학점, 인증필수 과목, 전문교양 인증선택 n과목, 기초→요소→종합 설계 순서(기초설계 전·종합설계 후 수강분 미인정), 종합설계 택1, 학과별 추가 조건(실험 과목, 일반영역 학점 등)을 확인합니다.
- **추천**: 미충족 필수 → 설계학점 → MSC → 전공 학점 순으로 과목을 고르되, 선택지가 있으면 희망 진로 키워드에 맞는 과목을 먼저 고릅니다. 권장 학년·개설 학기·학기당 학점 상한·설계 순서를 지켜 학기별로 배치합니다.
- **계획 시뮬레이터**: 추천 과목을 빼거나 듣고 싶은 과목을 원하는 학기에 넣으면, 나머지를 다시 짜고 그 계획으로 요건을 채우는지 바로 판정합니다.
- **체크표 미리보기**: 졸업심사 때 내는 ‘이수체계준수 상담표’와 ‘졸업심사서 과목이수 심사표’를 성적으로 미리 채워 보여 줍니다. 재수강 학기 표기, 설계학점, 선후수 준수 여부, 이번 학기 수강 과목을 반영하고 A4로 인쇄하거나 CSV로 받을 수 있습니다. 내 성적에 맞춘 작성 팁(재수강 증빙, 후수과목이수능력확인서 필요 여부, 설계 미인정 과목 등)과 공통 작성 요령, 제출 서류 예시도 함께 보여 줍니다.
- **학과 졸업요건 동시 판정**: 연도별 교과과정의 학과별 졸업학점, 교양 공통필수, 균형·학문기초교양, 전공기초·필수·선택, 졸업인증제(영어·고전독서·SW코딩)를 함께 따져 "공학인증 / 학과 졸업"을 나란히 보여 줍니다. 공학인증을 유지할 때와 포기할 때 남은 학점도 비교합니다.
- **최신 기준 적용**: 공학교육센터 안내대로 교과목은 입학 연도, 최소이수학점은 최신 연도 기준으로 계산합니다(설정에서 바꿀 수 있음). 종합설계를 듣는 학기까지 기초·요소설계 학점이 차 있는지도 확인합니다.
- **개설 강좌와 추천 시간표**: 현재 학기 수강편람(올클 공개 데이터)으로 추천 과목의 개설 여부를 표시하고, 원하면 공학인증·졸업에 필요한 과목과 진로 과목으로 시간이 겹치지 않는 시간표를 여러 안으로 짜 줍니다(쉬는 요일, 9시·18시 이후 제외 가능).
- **계절학기 추천**: 여름·겨울 계절학기 개설 강좌(올클 공개 데이터)에서 공학인증·졸업에 모자란 과목을 먼저, 남는 학점은 희망 진로 과목으로 골라 줍니다. 새 계절학기 강좌가 공개되면 예약 작업이 자동으로 반영합니다.
- **상담용 한 장 요약**: 판정, 졸업요건, 계획을 A4 한 장으로 인쇄합니다.
- **공지·설치**: 공학교육센터 최근 공지를 보여 주고, 홈 화면에 앱처럼 설치해 오프라인에서도 열 수 있습니다.
- **검증 도구**: `verify.html`(학과별 요건 원문 대조표), `node tests/run.js`(회귀 테스트).
- **대상**: 공학교육센터에 게시된 15개 인증 프로그램의 2021~2026학번 기준.

## 구조

```
index.html            화면
assets/engine.js      판정·추천 엔진 (Node에서도 require 가능)
assets/parser.js      성적표 텍스트/PDF 해석
assets/careers.js     진로별 과목 키워드
assets/sheet.js       체크표(상담표·졸업심사서) 미리 채우기, 작성 팁
assets/grad.js        학과 졸업요건 판정, 공학인증 유지·포기 비교
assets/timetable.js   추천 시간표
assets/app.js         화면 로직
assets/style.css
data/abeek.json       학과·학번별 인증요건과 이수체계표 (자동 생성)
tools/build_data.py   공학교육센터 페이지 수집 → data/abeek.json
tools/overrides.json  자동 추출 보정, 추가 조건
tools/build_grad.py   연도별 교과과정 → data/grad.json (학과 졸업요건)
tools/build_offered.py 수강편람(올클 공개 API) → data/offered.json, --season 으로 계절학기 → data/season.json
tools/build_notices.py 공학교육센터 공지 → data/notices.json
verify.html           요건 원문 대조표
tests/run.js          회귀 테스트
```

## 요건 데이터 갱신

새 학번 기준이 공학교육센터(abeek.sejong.ac.kr)에 올라오면:

```bash
pip install beautifulsoup4
python3 tools/build_data.py
```

자동 추출이 틀린 항목은 `tools/overrides.json`에 적고 다시 실행합니다.

## 한계

- 학번별 대체과목, 학과 공지로 바뀐 인정 과목, 실제 개설 여부는 반영되지 않을 수 있습니다. 화면에서 과목별 인증 영역을 직접 고칠 수 있습니다.
- 스캔(이미지) PDF는 글자를 읽을 수 없으니 표를 복사해 붙여넣어야 합니다.
- 최종 판정은 공학교육센터와 학과 사무실에서 확인하세요.

`main.py`는 이전 챗봇 시안의 FastAPI 백엔드로, 이 웹앱 동작에는 필요하지 않습니다.
